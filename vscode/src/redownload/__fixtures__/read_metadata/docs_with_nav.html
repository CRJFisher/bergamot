configure()

The configure() function sets the runtime options for the capture pipeline. It accepts a single options object and returns a frozen configuration that the pipeline reads on every visit. Call it once during activation; the returned value is immutable and safe to share.

Parameters

The options object supports the minimum text length below which a page is dropped as too small, and the maximum link density above which a page is treated as navigation chrome rather than content. Both have sensible defaults tuned against a sample of real captures, so most callers do not need to set them at all.

Return value

A frozen configuration object. Mutating it throws in strict mode. The pipeline reads the thresholds on each visit, so swapping the configuration atomically changes behaviour for subsequent pages without a restart.

Examples

The simplest call uses the defaults and is enough for the vast majority of deployments. Advanced users tuning recall against a specific corpus can raise or lower the thresholds and re-run the deterministic eval to confirm the keep/drop labels still match their expectations.

See also the configuration guide for a walkthrough of how the gate thresholds interact with the capture store and the downstream pipeline.
