The pipeline stages & the guarantees

A sequence of individually-testable stages with all clustering-tfjs calls isolated in one place, three determinism anchors, and a hard sample ceiling handled in order.

The stages — typed values flow forward, never backward

StageFunctionOutput typeNote
1fetch_visitsVisitRow[]Stable ORDER BY page_loaded_at, page_session_id; dedupe repeat visits.
2resolve_page_vectorsPageVector[]The only stage that touches vectors; re-download + embed + cache.
3reduce_dimensions(identity)OFF in v1. Deterministic PCA-50 is the first lever if guardrails trip; never UMAP.
4build_cosine_distance_matrixDistanceMatrixClamp D = max(0, 1−dot), diagonal 0, symmetrize. Dense O(n²) — the ceiling.
5run_hdbscanHdbscanRawThe only clustering-tfjs call. metric='precomputed', fit-only, no RNG.
6representationsRepresentedCluster[]Exemplar/medoid + frozen L2-normalized representative vector.
7deterministic_labelerClusterLabelHeadline + domain scope + keyphrases as separate fields; no LLM.

The determinism contract = three anchors, not one

The scope of “no seed”

Only the HDBSCAN micro-tier path uses no RNG (fit-only, deterministic parameter selection). This is not a global “no seed anywhere” rule — any medoid helper takes an explicit randomState, and the later SOM macro tier will require a seed.

The clustering-tfjs gate — the HDBSCAN upgrade is external

The ~5k dense-matrix ceiling — handled in order

A matryoshka-trimmed dim gives zero ceiling relief

A smaller source embedding cuts vector storage but the (n×n) matrix is the same size at any dimension. If reduction for clusterability is ever needed, the lever is deterministic PCA — not a smaller source model.
