The mental model

Two things define how to read a TDT result: what HDBSCAN groups on (embedding similarity) and what time is used for (windowing only). They are kept strictly apart.

Two axes — embedding clusters, time only slices

The one invariant to remember

HDBSCAN sees only the cosine distances between page vectors. Time decides the window; it never decides similarity. (Time returns later — for cross-window tracking — but never as an embedding dimension.)

A cluster = a set of pages = one candidate research thread

Noise (−1) = “pages in no project” — surfaced, not forced

Noise is a product feature

Most browsing is one-offs. Surfacing them honestly as noise is exactly the answer to “which pages belong to a project” — the ones that do not belong to any. Forcing them in would dilute every cluster.

Membership probability = core-vs-fringe ranking within a project
