The cache posture change

Privacy posture — the most important decision, amended first

The encrypted content cache moved from opt-in, scope-named population only to populated on the default read path: server_manager opens the cache during prepare() and wraps the live corpus in a CachedCorpus under scope "default", so every successful re-download persists its clean markdown body locally.

  • What does not change: the cache stays its own encrypted DuckDB file with its own OS-keystore key; every row is deletable and rides the right-to-forget cascade (task-39.5); the metadata record remains the only source of truth — the cache is derived, rebuildable, droppable.
  • What changed: content presence is now the norm rather than the exception. The user-authored amendment landed first — docs/decisions/default-path-content-cache.md — and docs/constitution.md and CLAUDE.md now describe the cache as default-populated, encrypted, derived.
  • Never load-bearing: a cache-open failure degrades the read path to live-only (the capture server still starts); per-page cache read/write failures are isolated and fall through to a live re-download. A degrade can never re-key the cache.
  • Why: the hero loop (TDT, then RAG) reads the corpus repeatedly; re-downloading the same public page on every read is slower, noisier toward remote hosts, and loses fetch-time fidelity. One politeness-gated fetch, then local encrypted reads.

Key design decisions

Decision · one parse

One Defuddle parse yields body AND metadata

do
parse_page(html, url) returns { body_markdown, metadata }; read_metadata.ts is deleted, not wrapped.
why
Defuddle already parses the full document to extract the body; its metadata (title, author, published, site, language) is richer than the regex head-scan. Two parsers over the same bytes is surplus.
honors
Constitution: no shims, no duplicate code paths. The fetcher slims to fetch · classify · hash.
Decision · privacy-critical

Force useAsync: false

do
Pass { markdown: true, useAsync: false } to Defuddle explicitly.
why
Defuddle's async extractors default to fetching content from third-party APIs when local extraction is thin.
honors
Bergamot is strictly local-only. This is a privacy gate, not a tuning default — it must never silently flip on.
Decision · privacy posture

Cache on the default path, scope "default"

do
enable_default_path_caching() (run from async prepare()) opens the encrypted ContentCache and wraps the live corpus in CachedCorpus(db, live, cache, "default"); ServerConfig gains optional secrets + storage_base — absent (headless standalone, tests), the read path stays live-only and caches nothing.
why
Repeated corpus reads (TDT, RAG, MCP) should not re-fetch public pages they already pulled. Exclusions still never enter the cache.
amended
docs/decisions/default-path-content-cache.md — the user-authored constitution amendment landed before this shipped (cache posture).
Decision · storage format

Brotli quality-5 BLOB body, not zstd, not plaintext

do
content is BLOB NOT NULL holding brotliCompressSync output at BROTLI_PARAM_QUALITY: 5 with a SIZE_HINT; reads decompress a DuckDBBlobValue (anything else is a stale pre-brotli file — wipe, never ALTER).
why
The VS Code extension host runs Node 20 — built-in zstd lands only in Node 22.15. Brotli is always present, zero-dependency, synchronous. Quality 5, not the default 11: the compress runs on the extension-host event loop per put, and the degrade path can hand it multi-MB raw HTML — q5 is ~10x faster with near-identical prose ratios.
note
content_hash stays the SHA-256 of the rendered HTML (fetch fidelity) — deliberately independent of the stored compressed body.
Decision · integration mechanic

Absolute-path require of defuddle/node

do
require.resolve("defuddle") finds the package main; the sibling node.js is then required by absolute path, cached once per process (load_defuddle).
why
defuddle/node exposes only an ESM import export condition, so a CommonJS require("defuddle/node") is rejected by the exports map — and a dynamic import() is no escape: under the CommonJS module target (the extension host and jest) it transpiles to that same rejected require.
note
The package's "." export carries a require condition, so its main resolves; the sibling node.js file is itself CommonJS — requiring it by absolute path sidesteps the exports gate in both the extension host and jest.
Decision · failure mode

Degrade to raw HTML, never lose the page

do
On an empty extraction or a parser throw, body_markdown is the raw HTML — not markdown — with URL-as-title metadata. Via the default-path cache, that raw HTML is what gets compressed and cached.
why
A noisy page is still better than a dropped page; extraction is an improvement, not a gate.
log
console.error("main-content extraction failed:", error) — generic and URL-free; the extension-host console persists to plaintext logs and URLs are sensitive browsing metadata, per corpus.ts's convention.
Decision · derived tier

Cache failures isolated; the forget race closed

do
CachedCorpus treats the cache as derived: a read failure logs (session id only) and falls through to a live re-download; a write failure is non-fatal. Before caching a fresh ok page, the metadata row is re-checked (cache_ok).
why
A forget can complete during the seconds-long live fetch; writing the page back afterwards would re-encode forgotten content — a right-to-forget violation. And a corrupt or pre-brotli store must never deny a page the live corpus can still serve.
note
A page whose metadata row is gone has its stale cache row deleted on sight — the 39.5 cascade's backstop, not its replacement.

// defuddle/node exposes only an ESM "import" export condition: a CommonJS
// require("defuddle/node") is rejected by the exports map, and a dynamic
// import() is no escape — under the CommonJS target (extension host and jest)
// it transpiles to that same rejected require. The package main ("." has a
// require condition) resolves; its sibling node.js is itself CommonJS —
// requiring it by absolute path sidesteps the exports gate.
function load_defuddle(): DefuddleModule {
  if (!defuddle_module) {
    const main_path = require.resolve("defuddle");
    const node_path = path.join(path.dirname(main_path), "node.js");
    defuddle_module = require(node_path) as DefuddleModule; // cached per process
  }
  return defuddle_module;
}

export async function parse_page(html: string, url: string): Promise<ParsedPage> {
  try {
    const { Defuddle } = load_defuddle();
    const response = await Defuddle(html, url, { markdown: true, useAsync: false });
    const body = response.content.trim();
    return {
      body_markdown: body.length > 0 ? body : html, // empty extraction → raw HTML
      metadata: {
        title: response.title.trim() || url,
        site_name: or_null(response.site),
        author: or_null(response.author),
        published_at: or_null(response.published),
        lang: or_null(response.language), // <html lang> — surfaced by Defuddle directly
      },
    };
  } catch (error) {
    // Degrade rather than lose the page. Log without the URL — the extension
    // host console persists to plaintext and URLs are sensitive metadata.
    console.error("main-content extraction failed:", error);
    return { body_markdown: html, metadata: { title: url, site_name: null,
      author: null, published_at: null, lang: null } };
  }
}

vscode/src/redownload/content_cache.ts — BLOB column, brotli q5 round-trip, lock-safe open
// Quality 5, not the default 11: the compress is synchronous on the extension-
// host event loop per put, and the degrade path can hand it multi-MB raw HTML —
// q5 is ~10x faster with near-identical prose ratios.
function compress_content(markdown: string): DuckDBBlobValue {
  const bytes = Buffer.from(markdown, "utf8");
  const compressed = zlib.brotliCompressSync(bytes, { params: {
    [zlib.constants.BROTLI_PARAM_QUALITY]: 5,
    [zlib.constants.BROTLI_PARAM_SIZE_HINT]: bytes.length,
  } });
  return blobValue(compressed);
}

vscode/src/redownload/cached_corpus.ts — the default-path wrap: hit, miss, degrade, and the forget race
async get_content(page_session_id: string): Promise<CorpusEntry | null> {
  const capture = await get_webpage_capture(this.metadata_db, page_session_id);
  if (!capture) { await this.evict_stale(page_session_id); return null; } // 39.5 backstop
  const cached = await this.read_cache(page_session_id); // read failure → logged miss → live
  if (cached) return { outcome: "ok", content: cached };  // hit: no network
  const entry = await this.corpus.get_content(page_session_id);
  if (entry && entry.outcome === "ok") await this.cache_ok(page_session_id, entry.content);
  return entry; // exclusions re-classify on every read — never cached
}
private async cache_ok(page_session_id: string, content: CorpusContent): Promise<void> {
  // A forget can complete during the seconds-long live fetch; writing the page
  // back afterwards would re-encode forgotten content. Re-check the metadata row.
  const still_present = await get_webpage_capture(this.metadata_db, page_session_id);
  if (!still_present) return;
  try { await this.cache.put(content, this.scope); }
  catch (error) { console.warn(`content cache write failed for ${page_session_id}:`, error); } // non-fatal
}

 // constructor: this.base_corpus = config.content_corpus ?? this.build_redownload_corpus();
 //              this.content_corpus = this.base_corpus;   // the wrap is reversible

 private async enable_default_path_caching(): Promise<void> {
   if (this.config.content_corpus) return;                  // injected corpus: bypass
   if (!this.config.secrets || !this.config.storage_base) return;
   if (this.content_cache) return;                          // idempotent
   try {
     // Lazy import: content_cache.ts pulls in `vscode`, absent in the standalone.
     const { open_content_cache } = await import("../redownload/content_cache");
     this.content_cache = await open_content_cache(this.config.secrets, this.config.storage_base);
     this.content_corpus = new CachedCorpus(this.config.duck_db, this.base_corpus, this.content_cache, "default");
   } catch (error) {
     // Cache-open failure degrades to the uncached live corpus — the cache is a
     // derived tier, and a degrade can never re-key anything.
     console.warn("Bergamot: content cache unavailable; serving re-downloads live without caching.", ...);
   }
 }

 async prepare(): Promise<void> {
