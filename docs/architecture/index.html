Bergamot

Transform your web browsing into a queryable knowledge base, accessible via MCP for AI-powered PKM workflows.

Browser extension → VS Code backend → DuckDB + LanceDB → MCP / HTTP query

Bergamot silently captures knowledge-rich pages as you browse, processes them with an LLM, stores them in structured and vector backends, and exposes them to AI agents through an MCP server. The system has two deployable artifacts — a Chromium browser extension (capture) and a VS Code extension (process, store, serve) — that communicate over a single local HTTP transport.

2The four subsystems

🌐 Browser Extension →

Chromium MV3 extension. Captures page HTML, compresses it, and maintains the cross-tab navigation session graph before posting visits to the backend over HTTP.

content.ts · background.ts

🧩 VS Code Extension →

The backend host. Runs the Express ingest server, durable inbox, batch processor, and the LLM-driven processing workflow that classifies pages and builds navigation trees.

extension.ts · WebpageWorkflow

💾 Storage Layer →

Two complementary stores: DuckDB for relational visit records, and LanceDB for page content + vector search.

DuckDB · LanceDB

🔌 MCP & Query →

The access layer. A standalone MCP server plus a read-only HTTP query API expose the knowledge base to AI agents and external scripts.

6 MCP tools · /query/*

🔎 RAG Pipeline →

Current baseline and the phased upgrade plan: hybrid search, contextual chunking, reranking, and an evaluation harness to measure each step.

capture → chunk → embed → retrieve → rerank

Sequence — a single page visit, from browse to stored

    U->>C: navigates to page
    C->>C: extract HTML, compress (zstd)
    C->>B: sendMessage(visit)
    B->>B: enrich with referrer, group_id, opener
    B->>S: HTTP POST /visit (discover port 5000–5009)
    S->>Q: persist to inbox, enqueue, return 200
    Note over B,S: browser is acknowledged immediately
    Q->>W: run(members, new_page, raw_content)
    W->>W: LLM extract → Markdown
    W->>W: classify + filter
    W->>W: assign to navigation tree
    W->>DB: write relational + vectors
    W-->>Q: remove inbox file (durably ingested)
